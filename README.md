# SAZ 作戦ボード

サドンアタック：ゼロポイント（SAZ）の爆破戦で、攻め方の配置・順番と、地点間の移動時間を図にする道具。

- `index.html` 作戦ボード（駒・順番つき矢印・煙/閃光/C4・PNG 書き出し）
- `editor.html` 移動時間エディター（赤=攻め・青=守りの点、曲げ点つき通路、縮尺コース、武器切替 ナイフ/P90/SCAR・AK/M249/歩き、全地点間の表、PNG 書き出し）
- `data/mobility.md` 武器ごとの移動速度の実測（2026-10-04）
- `patterns/png/` 攻め方の見本画像、`data/timemap/png/` 移動時間マップ画像

GitHub Pages で開いた時は保存サーバーが無いので、編集画面は「JSONを保存(ファイル)」で保存して Claude に渡す。
俯瞰図は原作サドンアタックの 2012 年のブログ掲載画像（個人の研究用）。
