# saz-board 作業の記録

## 2026-10-04 初版
利用者の依頼: 「サドンアタックのマップで攻め方のバリエーションを説明できるように、人の配置を画像にしたい」。
聞いた答え: マップは今ある全部／自分で駒を置けるボード＋私が描いた見本画像の両方／下地はゲームの俯瞰図（無ければ簡略図）／駒には役割名と動く順番・矢印。

### 下地の入手経緯
- SAZ の公式・Wiki（saz.wiki, sazwiki.wiki, gamerch）に俯瞰図は無い。あるのはプレイ画面のスクショだけ。
- ゲーム内で BOT MODE に入って全体図を撮る案は、画面操作の許可が却下されたので中止。
- 原作サドンアタックの 2012 年のブログ「マップ名称(初級者･中級者用)」にコールアウト入り俯瞰図があり、SAZ と同じ名前の 4 マップ分を使った:
  第3補給倉庫 / プロバンス / クロスポート / ドラゴンロード（`maps/raw/ameblo_*.jpg`、出所は `maps/raw/ameblo.html`）。
  同ブログのオールドタウンは SAZ に無いので不使用。ウェアハウスの図は削除済みで取れなかった。
- SAZ 新規の 地下鉄・シティキャット と TDM の ウェアハウス・サドン村 は下地なし。**利用者がゲーム内の全体図をスクショしてドロップすれば使える**。

### 作った物
- `index.html` 作戦ボード（移動／経路／煙／閃光／C4／文字／消す、役割、順番①②③、点に合図の文字、保存・JSON・PNG、下地ドロップ）
- 見本 16 本 = 4 マップ × （Aラッシュ／Bラッシュ／スプリット／デフォルト）。`patterns/png/` に PNG 済み
- 守りの駒も各見本に定位置（アンカー×2・ローテ・スナイパー・情報取り）で置いてある

### 注意
- 俯瞰図は原作のもの。SAZ 版リメイクで細部（箱の位置・通路）が違う可能性がある。地名の座標は私が目で置いた概算
- 見本の攻め筋は一般的な爆破戦の定石＋ブログの地名から組んだもので、SAZ の実戦で検証していない。利用者の手で直す前提

### 残件・次にやるなら
- 利用者からゲーム内の全体図のスクショをもらって 地下鉄・シティキャット の下地と見本を作る
- 利用者の実戦の感覚で見本の経路・守り位置を直す（ボード上で直して JSON 書き出し → `patterns/` に置けば見本になる。index.json に 1 行足す）
- 要望があれば「攻守反転（守りの配置バリエーション）」「フェーズ別の複数コマ表示」

## 2026-10-04 追記: 武器の機動力データ
- 依頼: P90 / AK-47 / M249（＋ナイフ）の足の速さの倍率と単位時間あたりの距離を、攻め込む時の参考にデータ化。
- 公式・Wiki・韓国側のどこにも実速度は無い。ゲーム内表示の「機動力」だけ → `data/weapons.json`・`data/mobility.md` にまとめ、ボード右下に表を出した。
- 本人の判断: **今は機動力の数値だけで良い**（実測は後回し）。実測するなら 第3補給倉庫 Bロング を W 押しっぱなしで走って壁に当たるまでの秒数（各3回・ナイフ基準）。私が BOT MODE で測るには画面操作の許可が要る。

- 追加依頼: 歩きの速度も。→ 公式・Wiki・韓国側に走りとの比の数値は無し。data に「未公開・実測待ち」として姿勢の表を足し、実測計画を 4武器×3姿勢 に拡張。

## 2026-10-04 実測を実施（本人と共同）
- 本人が画面操作の許可を出し直し、マップトレーニング（訓練場→マップトレーニング→第3補給倉庫）で測った。
- 役割分担: **本人**が位置・向き・武器を整えて毎回スタートへ戻す／**私**が W（歩きは Shift+W）を押しっぱなしにして時間を測る。
- 時間の取り方: `tools/speedtest.py --record` で画面中央（武器と HUD を避けた上半分）の前コマとの差分を 30fps で記録し、`--analyze` で「動き出し（差分>1.5 が3コマ）」→「壁（走行時水準と壁水準の中間を下回り続ける最初）」を出す。ナイフの素振りのスパイクは 9 コマ中央値で均す。録画の終わりに本人が動いても壊れないよう、キー離しは最初の静止プラトーで取る。
- 落とし穴: 私の SendInput のキー・マウスはゲームに無視される（computer-use の hold_key は効く）。ミニマップは透過で下の景色が混ざるので距離測定に使えない。壁に斜めに当たると壁ずりで到着が取れないことがある。ラグが入った本は本人申告で除外。
- 結果は `data/mobility.md` の「実測」節と `tools/runs/results.json`。AK は SCAR で代用（本人判断）、しゃがみは未計測。
