この画面でできること

サドンアタックのマップに「点」を置いて「通路」でつなぐと、点から点まで走って何秒かかるかが武器ごとに出ます。 赤の点＝攻めが立つ場所、青の点＝守りが立つ場所です。 表を見れば「ここからあそこへ回り込むのに P90 なら何秒、M249 なら何秒」が分かります。

流れ：  ① マップを選ぶ → ② 点を置く → ③ 通路でつなぐ → ④ 曲げて壁を避ける → ⑤ 保存
        （精度を上げるなら ⑥ 縮尺コースを打つ）  → 右の表・PNG で使う

① マップを選ぶ

左上のプルダウンで選びます。地下鉄・シティキャットなど俯瞰図が無いマップは格子だけが出るので、ゲーム内の全体図（マップ画面）をスクショして、この画面にドラッグ＆ドロップしてください（または 下地: 画像を選ぶ）。一度入れるとこのブラウザが覚えます。

② 点を置く

  1. 赤の点（攻め）か 青の点（守り）を押す
  2. 地図の置きたい場所をクリック → 名前を聞かれるので「Bロング」「CT階段」などと入れる
  3. 続けて何個でも置ける。やめる時は 動かす を押すか Esc

③ 通路でつなぐ

  1. 引く を押す
  2. 点を 1 つクリック → もう 1 つの点をクリック。白い線（通路）がつながる
  3. 線の真ん中に秒数が出る（上の「秒数」で選んだ武器の時間）
つないだ線は「人が実際に走る道」です。壁を突き抜けていると秒数が短く出てしまうので、次の「曲げ点」で道なりにしてください。

④ 曲げて壁を避ける

  1. 曲げ点 を押す
  2. 曲げたい通路をクリックして選ぶ（黄色くなる）
  3. 人が通る所を順にクリックすると、そこを通るように線が折れる（白い四角＝曲げ点）
動かす にすると、点も曲げ点もドラッグで位置を直せます。消す で点・通路・曲げ点をクリックすると消えます（通路を選んで Delete でも消える）。

⑤ 保存

  • 自分のパソコンで開いている時（localhost）: 保存 を押すだけ
  • GitHub のページで開いている時: JSONファイル でファイルを落として保管。次に開く時は JSON読む でそのファイルを選ぶと戻る
保存前に別のマップへ切り替えたりリロードすると、打った物が消えます。こまめに保存してください。

⑥ 縮尺コースを打つ（秒数を正確にする）

秒数は「画面の長さ ÷ 1 秒に進む長さ」で出しています。マップごとに 1 回、実際にゲームで走って秒数を測ったコースを教えると正確になります。

  1. ゲームでナイフを持ち、どこかの壁からどこかの壁まで W 押しっぱなしで走って秒数を測る（第3補給倉庫の Bロングは 8.97 秒）
  2. コースを打つ を押し、走り始めた所 → 走り終わった所の順にクリック
  3. かかった秒数を入れる → 緑の点線で表示され、「実測 ○○px/秒」になる。保存 で確定
打っていないマップは「仮」として第3補給倉庫の縮尺を流用します。目安にはなりますが、マップによって絵の大きさが違うので、本気で使うなら 1 本測ってください。

右の欄の見方

  • 通路（px・秒・比率）: 引いた線ごとの長さと秒数。基準 を押した通路が 1.00 になり、他の通路はその何倍かが出る。× で消せる
  • 全地点間の移動時間: 全部の点どうしの最短の秒数（通路をたどった合計）。「―」はつながっていない
  • 地点: 置いた点の一覧。× で点ごと消せる

秒数の武器を変える・画像にする

  • 上の「秒数」プルダウンで ナイフ / P90 / SCAR・AK-47 / M249 / 歩き を切り替え。線の秒数と表が全部変わる
  • 「線に秒数」のチェックを外すと線の数字を隠せる（点を打つ時に見やすい）
  • PNG（この武器） で今の武器の画像、PNG（全武器） で 5 枚まとめて保存。地図＋右の表が 1 枚に入る
速さの元データ（実測）: ナイフ 8.97 秒のコースを P90 9.07 / SCAR 9.44 / M249 12.15 / 歩き 13.47 秒。歩きはどの武器でも同じ。しゃがみは未計測。

困った時

  • 線が引けない → 点の「上」をクリックしているか確認（丸の中）
  • 間違えて置いた → 消す でクリック、または右の一覧の ×
  • 全部やり直したい → 全部消す（縮尺だけは残る）
  • 一覧にマップが増えない・直したはずの物が古い → Ctrl+F5 で読み直す

赤/青の点: 地図をクリック → 名前。引く: 点を2つ順にクリック。曲げ点: 通路を選んで通る所を順にクリック。
縮尺: 実際に走ったコースの始点と終点をクリック → 何秒かかったか（ナイフ走り）を入れる。
基準: 表の「基準」を押した通路が 1.00 になり、他はその何倍かが出る。
